# Daily Journal with AI Writing Prompts

## 📖 About the Project

**Daily Journal with AI Writing Prompts** is a simple web application that helps users write and maintain their daily journal entries.

The application provides **AI-powered writing prompts** to help users when they are unsure what to write about.

## ✨ Features

* 📝 Create daily journal entries
* 🤖 Get AI-generated writing prompts
* 📅 View journal entries by date
* ✏️ Edit existing entries
* 🗑️ Delete journal entries
* 💾 Save journal entries
* 🔍 View previous journal entries
* 📱 Simple and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* React.js
* Node.js
* Express.js
* Database
* AI API

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd Daily-Journal
```

### 3. Install dependencies

For the client:

```bash
cd client
npm install
```

For the server:

```bash
cd ../server
npm install
```

### 4. Start the server

```bash
npm start
```

### 5. Start the client

Open another terminal:

```bash
cd client
npm run dev
```

Then open the local URL shown in the terminal.

## 🤖 AI Writing Prompts

The AI feature can generate prompts such as:

* What was the best part of your day?
* What did you learn today?
* What are you grateful for?
* What is something you want to improve?
* What are your goals for tomorrow?

## 🎯 Purpose

The main purpose of this project is to make daily journaling **easy, organized, and engaging** with the help of AI-generated writing prompts.
